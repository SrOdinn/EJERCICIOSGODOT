# Entrega Proyecto v0.1 — 8 de noviembre de 2026

La entrega de **Torrente: La Última Ronda** está en la carpeta [`Torrente_v3`](Torrente_v3).

1. Descargar o clonar el repositorio.
2. Importar **`Torrente_v3/project.godot`** en Godot 4.7 o posterior.
3. Pulsar **F5** para jugar.

Incluye el escenario «Al Casi, Pero No», sus colisiones, una cerveza que se recoge al pasar, reaparición aleatoria y 2 segundos acumulables de turbo por recogida. Las partidas duran 60 segundos.

**Controles:** WASD o flechas para moverse; R para reiniciar.

[Instrucciones del proyecto](Torrente_v3/LEEME.md)

## Mejora del mapa jugable

Actualizado el escenario con la decoración nueva, los pasillos despejados y sus hitboxes. Las cervezas aparecen en puntos accesibles desde la entrada.
