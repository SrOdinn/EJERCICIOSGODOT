# Ejercicios Godot T2.3

## Puesta en marcha

1. Abrir Godot 4.
2. Importar el archivo `project.godot`.
3. Pulsar F5 para ejecutar el juego.

## Controles

- **W, A, S y D:** mover al personaje.
- **Espacio:** recoger la moneda si está cerca y sumar un punto.

La partida dura 30 segundos. Al terminar, el personaje se detiene y aparece la puntuación final.

Para empezar otra partida, detener la ejecución con F8 y volver a pulsar F5.
